    Reader help

    TheCrumbs.org logo / Quit
    Return to the homepage. Before the first move to another crumb, leaving never triggers a save warning, even if favorites or settings have changed. After navigation, unsaved changes trigger a confirmation. Returning to the initial crumb does not reset this rule.
    Load session
    Choose a text file previously saved by the Reader. It restores the current crumb, visited list, favorites, random mode, viewing history, and text size. It replaces the active session, while the browser’s saved copy stays unchanged.
    Save session
    Choose browser storage, a text file, or Cancel. Saving is manual and is available at any point.
    Save in this browser
    Replace this browser’s saved session. It is restored automatically when the Reader opens. This copy stays in this browser profile.
    Text file name / Save as a text file
    Enter a filename and save a portable copy that can be loaded on another computer or phone. The browser controls the download location and whether a Save As dialog is available.
    Go to
    Enter a valid crumb number and select Go to crumb to display it directly. Cancel keeps the current crumb.
    Favorites
    Open the list of favorite crumbs, ordered numerically. Select a number and title to read that crumb, or Close to return.
    Back / Forward
    Retrace the actual viewing sequence, including reference links and favorites. The session keeps up to 100 history entries. These controls remain available in random order whenever history permits.
    Random Order
    Make Next choose a random crumb that has not been visited. Previous is disabled. When all crumbs have been visited, a dialog offers a new round; restarting clears the visited list and keeps favorites and history.
    Previous / Next
    Read the preceding or following crumb in numerical order. In random order, Next selects an unvisited crumb. Next is disabled at the last crumb in numerical order.
    Favorite
    Add the displayed crumb to Favorites. Clear the checkbox to remove it.
    A− / A+
    Decrease or increase the size of the crumb title and body. The setting is included when the session is saved.
    Numbered references
    Select a linked crumb number to read the referenced crumb. Back returns to the original crumb.
    Website links
    Open the address in another tab or window, according to browser preferences. The Reader stays open.
    Browser Back / Forward
    Navigate the crumb entries created during this visit. Loading a saved session restores history for the Reader’s own controls, without recreating the browser’s entire history. When leaving the Reader, eligible unsaved changes also request the browser’s standard warning; browsers may suppress that warning.
    Saved / Unsaved changes
    Show whether the current session matches its last save or loaded file. Initial-crumb changes can still be saved manually even though leaving before navigation does not warn.
    Cancel / Close / Stay here
    Dismiss the corresponding dialog without carrying out its proposed action. Confirmation buttons perform the action stated in the dialog.
    Try again
    Retry loading the collection if it could not be fetched.
    Help
    Open these explanations on computers or phones. Hover over a control or focus it with the keyboard for its individual hint. Escape dismisses a visible hint.
