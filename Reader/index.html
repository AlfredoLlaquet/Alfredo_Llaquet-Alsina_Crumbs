    Crumb Reader help

    Reading another crumb

    The controls at the bottom of the Crumb Reader move between crumbs. On phones, they appear as symbols; the yellow hints show their names.

    • Previous / Next are the straight arrows. Use them to read the previous or next crumb in numerical order. During a search, they move between matching crumbs.
    • Back / Forward are the curved arrows. Back returns to the crumb viewed before the current one. Forward retraces those steps after Back has been used.
    • Random is the crossed-arrows button. It chooses a crumb that has not been visited in the current session. During a search, it chooses from the matching crumbs not yet visited during that search.

    The visited count shows how many different crumbs have been opened in the current session. Opening a crumb already visited does not increase that count.

    When Random runs out of unvisited crumbs, a message offers Start new round. Outside a search, this starts the visited count again. During a search, it allows matching crumbs to be chosen again without resetting the overall visited count. Favorites and viewing history are kept.

    Search

    Select the magnifying glass at the top left of the controls to open the Search in the crumbs form. Choose an option under Search by, enter what to find, and select the form’s Search button.

    • Text: find a word or a continuous phrase in crumb titles and text. Uppercase and lowercase letters are treated alike. Text searches also match the names of recurring characters, places, concepts, and more with any of their aliases. For example, “universe 12” also matches “band universe” and “universe band”; “crumb-smith” also matches “Alfredo,” “multi-god,” and other aliases.
    • Crumb number: enter a number to go directly to that crumb. This also ends any active search.
    • Regular expression: search for a pattern rather than an exact word or phrase. Enter a pattern on its own for a case-sensitive search, or use /pattern/flags. For example, /cake/i finds “cake” without distinguishing uppercase and lowercase letters. For an introduction to regular expressions, see A Beginner’s Guide to Regular Expressions.

    A new text or regular-expression search opens the first matching crumb in numerical order. If nothing matches, or Cancel is selected, the current crumb and any existing search stay as they were.

    While a search is active, matching text is highlighted. The blue bar shows the current crumb’s position among the matching crumbs.

    • Previous / Next move to the previous or next match in numerical order, whether it has been visited or not. At either end, a message says there are no earlier or later matches.
    • Random chooses a match not yet visited during this search. A crumb visited before the search began can still be chosen. This separate record of visits is used only by Random; new visits also count toward overall reading progress.
    • Back, Forward, Favorites, and crumb numbers inside a crumb can open other crumbs without ending the search. If the displayed crumb does not match, the blue bar says so.

    To end the search and keep reading the displayed crumb, click or tap its text. Scrolling, selecting text, and selecting a crumb number keep the search active. The Escape key also ends the search when no form or Help is open.

    The yellow ? in the Search form opens this section. Close help returns to the form with the chosen search type and entered text preserved.

    For experts: the Crumb Reader uses ECMAScript (JavaScript) regular expressions.

    Favorite / Favorites

    Select the Favorite star at the bottom to mark the current crumb. A filled blue star means it is a favorite. Select the star again to remove that mark.

    To return to a favorite, select Favorites at the top. The Favorites form lists the marked crumbs by number and title, in numerical order. Select an entry to read it, or select Close to keep reading the current crumb.

    Save

    Select Save at the top to open the Save session form. A saved session keeps the current crumb, visited count, Favorites, viewing history, text size, and any active search, so reading can continue later.

    The Save session form contains these controls:

    • Enable auto saving in this browser button: turn on automatic saving. The Crumb Reader saves changes shortly after activity stops. When it is on, this button changes to Disable auto saving in this browser. Selecting either button saves the current session and the choice immediately.
    • Save now in this browser button: save the current session here now. The Crumb Reader restores it automatically when it is opened again in the same browser. This button is unavailable when the browser already has the current session saved.
    • Erase current browser data button: delete the Crumb Reader’s saved session in this browser and turn off auto saving. The session currently open can still be read, and previously downloaded session files are kept. This button is unavailable when there is no saved session to erase.
    • Text file name field: choose a name for a downloaded copy of the session.
    • Save as a text file button: download that copy. Keep it to load later, including on another computer or phone. Auto saving does not update downloaded files; use this button again to save a newer copy.

    This browser keeps one saved session, so a new browser save replaces the previous one. To keep separate sessions, save them as text files with different names.

    Select Close to leave the form. If saving fails, the form explains the problem. A text file can be used when saving in the browser is unavailable.

    Load

    Select Load at the top. In the file chooser, select a text file created with Save as a text file. The Crumb Reader restores the session from that file, including its reading position, Favorites, visited count, viewing history, text size, and saved search.

    If the current session has unsaved changes, the Load another session confirmation asks whether to replace it. Select Load session to use the file or Cancel to keep the current session.

    The file also restores its auto-saving choice. If auto saving is on, the loaded session is saved in this browser. If it is off, the browser’s previously saved session is kept until a new browser save is made.

    A− / A+

    Select A− to make the crumb’s title and text smaller, or A+ to make them larger. A button becomes unavailable when its size limit is reached. Saving the session also saves this choice.

    Crumb numbers inside a crumb

    Select a crumb number inside a crumb to read that other crumb. Use the curved Back arrow at the bottom to return.

    TheCrumbs.org logo / Quit

    Select the logo or Quit to return to the home page of TheCrumbs.org.

    After moving to another crumb, leaving with unsaved changes opens the Return to TheCrumbs.org confirmation. Select Stay here and save to open the Save session form, or Return home to leave without saving those changes. Before moving to another crumb, leaving does not show this confirmation.

    Help and control hints

    Select the yellow ? in the Crumb Reader’s top controls to open this Help. On a computer, pointing at a control with the mouse or reaching it with the keyboard also shows a short explanation of that control.

    On phones, yellow labels identify the controls when the Crumb Reader opens. The first tap or key press hides those labels and still carries out the chosen action. Opening the Crumb Reader’s Help shows the labels again behind it. After Close help, they stay visible until the next tap or key press in the Crumb Reader.

    Messages, Cancel, and Close

    Forms and messages name the action available. Cancel leaves the proposed action undone. Close returns to reading, and Close help returns to the Search form when Help was opened there.

    If the crumbs cannot be loaded when the Crumb Reader opens, select Try again to retry.
